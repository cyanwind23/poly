Deploy Multi-App Kubernetes Stacks With One Clean values.yaml

Poly is a Kubernetes Helm library/subchart with smart inheritance (default → <appName>), concise shortcuts, schema validation, and cloud-native integrations for GitOps teams.

Read Full Docs Release v3.1.0 Helm Repo Index

Quick Start

Add Helm Repository 
helm repo add poly https://cyanwind23.github.io/poly/
helm repo update
helm search repo poly
Chart.yaml (Use as Subchart Dependency) 
apiVersion: v2
name: my-stack
type: application
version: 1.0.0

dependencies:
  - name: poly
    repository: https://cyanwind23.github.io/poly/
    version: "3.1.0"

Key Capabilities in v3.1.0

Workloads & Smart Defaults

Supports Deployment, StatefulSet, DaemonSet, Job, and CronJob with automatic OnFailure and conditional probes/services.

External Secrets Operator (v1)

First-class ExternalSecret & SecretStore / ClusterSecretStore (external-secrets.io/v1). Raw inline Secrets in Git are blocked by schema.

Quick Volume Mounts

Mount created or pre-existing (exists: true) ConfigMap, Secret, and PVC resources directly via mountPath and -prefix naming.

Gateway API & Cilium

Native HTTPRoute / GRPCRoute (gateway.networking.k8s.io/v1) plus CiliumNetworkPolicy and CiliumEnvoyConfig (cilium.io/v2).

ArgoCD & Progressive Delivery

Image tag precedence (image.tag > quickConfigs.registry) for ArgoCD Image Updater, plus Argo Rollouts Blue-Green previews.

Schema Validation & Tests

Built-in values.schema.json (Draft 7) catches invalid types, enums, and inline secrets at helm lint / helm template time.
